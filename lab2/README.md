# Lab 2: Component Diagrams and Architectural Justification

## 🎯 Objectives
- Model the structural decomposition of the software system into loosely coupled components.
- Specify provided and required interfaces (ports, APIs) between subsystems.
- Justify architectural choices against non-functional requirements (scalability, maintainability, modularity).

## 📁 Deliverables
- Lab2_UML_Component_Diagram.pdf: UML Component diagram detailing subsystems, database components, controllers, and services.
- Lab2_Architecture_Justification.pdf: Architectural justification document explaining architectural style, decoupling strategy, and interface design.
