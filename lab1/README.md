# Lab 1: Use Case Diagrams and Requirements Engineering

## 🎯 Objectives
- Identify actors and high-level use cases for the target system.
- Map business and functional requirements into an organized requirements table.
- Detail use case scenarios including primary flow, alternate flows, preconditions, and postconditions.

## 📁 Deliverables
- Lab1_UML_Use_Case_Diagram.pdf: UML Use Case diagram illustrating system boundaries, actors, and use cases.
- Lab1_Requirements_Table.xlsx: Tabulated mapping of functional requirements, priority levels, and IDs.
- Lab1_Use_Case_Flow.docx: Detailed specifications of the use cases, happy paths, and exception flows.
